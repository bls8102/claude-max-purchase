## 先确认：你买的是哪一档

Claude 的个人订阅目前分三档，官方页面上的价格一直没变：

- **Pro：$20/月**，年付 $200/年，折下来约 $16.7/月

Max 是 Anthropic 给重度用户的档位，5x 和 20x 的差别集中在用量倍数上——5x 大约是 Pro 的 5 倍，20x 再翻 4 倍。除此之外，Max 相对 Pro 还有两点实际差异：单次输出上限更高（生成大段代码时不容易被截断），以及新功能和高峰期访问的优先级靠前。

## 国内付款到底卡在哪一步

卡点比想象中集中：

Anthropic 在 Stripe 那边会校验卡头（BIN），也就是发卡国家。中国大陆和港澳地区发行的信用卡、借记卡，基本在支付环节就被判定为不支持，不会走到「封号」那一步，而是直接拒付。部分双币卡偶尔能过，成功率不稳定，续费时还可能被拒。

PayPal 也解决不了这个问题。Anthropic 支持 PayPal，但你的 PayPal 得绑定海外卡才能付美元；国内 PayPal 默认只能绑银联卡，等于换了个支付通道又回到原点。

所以国内用户的现实选择，基本就是下面这几条。

## Max 5x 还是 20x：先算用量再掏钱

「倍数」不等于「条数」。有开发者通过抓包分析过实际额度字段，得出的限额结构是这样的：

| 档位 | 5 小时窗口限额 | 周限额 |
| --- | --- | --- |
| Pro | 550,000 credits | 5,000,000 |
| Max 5x | 3,300,000 credits | 41,666,700 |
| Max 20x | 11,000,000 credits | 83,333,300 |

能看出两层限制是叠加的：5 小时滚动窗口管短期节奏，周上限管总量。而且**网页、桌面端、移动端和 Claude Code 共用同一个额度池**——用 Claude Code 跑一天长任务，网页聊天的额度也跟着掉。

撞到限额后有两条路：等窗口重置，或者开启 usage credits，按标准 API 费率继续干活。credits 是救急价，长期靠它续命不如直接评估要不要升档。

所以判断标准其实很粗糙但有效：

- 每天用 Claude Code 干活超过 2 小时，而且已经把 Pro 的额度撞过墙 → 5x 大概率比按量付 API 便宜；
- 全天挂 Agent、多任务并行、经常打满周限额 → 20x 才有意义；
- 一周只有两三天高峰、其余时间用不到 → 先算 API 按量账，固定月费可能吃不满。

有个容易踩的坑：5x 和 20x 的单位性价比其实一样（按 credits 换算都约为 13.5 倍等效 API 价值）。也就是说 20x 不是「更划算」，只是「额度更大」。用不完就是纯浪费，$200 一个月不会因为你升档而变得更值。

## 常见问题

**Q：能不能直接用国内银行卡付？**
基本不行。Anthropic 会校验发卡国家，中国大陆和港澳的卡在支付环节就会被拒。部分双币卡偶尔能过，但续费不稳定。

**Q：代付需要把 Claude 密码给对方吗？**
正规流程不需要。插件获取的是 Session 凭据，不是密码。凡是要求你直接提供账号密码的平台，都建议绕开。

**Q：订阅是开在我自己的账号上吗？**
BeWild 这类平台做的是「给你自己的账号开通订阅」，不是卖成品号。这一点在对比时值得单独确认，因为「成品号」和「给自己账号代充」是两种完全不同的产品。

**Q：Max 支持退款吗？**
Anthropic 官方对订阅退款有自己的规则，第三方平台则各家不同。下单前先把退款条款看一遍，尤其注意「订阅已生效」之后是否还能退。

**Q：付完多久生效？**
一般支付完成后几分钟到几十分钟内生效，具体看平台当时的处理队列。生效后在自己的 Claude 账号里能看到对应的会员权限。
